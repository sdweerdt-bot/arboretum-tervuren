    Publiceren instellen (eenmalig per toestel)

    De site staat op GitHub. Om vanaf deze pagina te publiceren, heeft dit toestel een sleutel nodig die enkel deze repository mag aanpassen:

    1. Ga op github.com naar Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Kies bij Repository access: Only select repositories → arboretum-tervuren.
    3. Bij Permissions → Repository permissions → Contents: Read and write. Zet een vervaldatum naar keuze.
    4. Kopieer de sleutel en plak hem hieronder. Hij wordt enkel op dit toestel bewaard.

    Liever geen sleutel? Gebruik Download als bestand en bezorg het bestand aan Claude.
